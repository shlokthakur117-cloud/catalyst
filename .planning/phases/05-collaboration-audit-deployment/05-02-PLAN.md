# Plan 05-02: Shared Care Timeline & Immutable Audit Log Explorer

## Objective
Provide a unified, chronological timeline of all care actions (doses, alerts, claims, medication changes, appointments) and an immutable audit log view.

## Tasks
1. Implement timeline aggregation service (`src/services/timeline-service.ts`) merging dose confirmations, alert resolutions, and appointments.
2. Build Shared Care Timeline component displaying interactive event cards with timestamps and actor badges.
3. Build Audit Log viewer displaying cryptographic/immutable before-and-after change diffs.
4. Support medication change history tracking with author attribution.

## Acceptance Criteria
- Timeline presents all care events in descending chronological order.
- Audit log displays before/after state diffs clearly.
