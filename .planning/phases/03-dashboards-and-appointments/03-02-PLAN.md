# Plan 03-02: Caregiver Command Center & Multi-Elder Selector

## Objective
Build a dense, actionable caregiver dashboard for monitoring adherence, pending alerts, and managing medications.

## Tasks
1. Build caregiver dashboard header with linked elder selector.
2. Display adherence rate metrics (e.g., % taken on time this week).
3. Display real-time list of today's doses categorized by status (`taken`, `not_yet`, `unsure`, `unconfirmed`).
4. Provide quick modal to add/edit medications and schedules.

## Acceptance Criteria
- Caregiver can toggle between multiple linked elders.
- Adherence calculation accurately reflects verified doses.
