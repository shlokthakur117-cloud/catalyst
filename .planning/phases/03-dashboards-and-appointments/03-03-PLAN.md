# Plan 03-03: Medical Appointments & Companion Notes

## Objective
Implement appointment management allowing caregivers and elders to schedule visits, track clinic details, and add companion notes.

## Tasks
1. Implement appointment service (`src/services/appointment-service.ts`).
2. Build appointment list and scheduler dialog with doctor name, clinic address, date, time, and companion notes.
3. Show upcoming appointment banners on both elder and caregiver dashboards.
4. Add unit tests for appointment service.

## Acceptance Criteria
- Appointments display chronologically.
- Elder view displays simplified appointment reminder cards.
