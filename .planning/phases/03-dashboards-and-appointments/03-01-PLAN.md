# Plan 03-01: Elder-Friendly Accessible Touch Dashboard

## Objective
Deliver an ultra-high-accessibility, elder-friendly UI optimized for seniors with visual impairment or motor stiffness.

## Tasks
1. Implement elder UI layout with high contrast (WCAG AAA compliant, contrast >= 7:1) and large fonts (>= 18px base).
2. Build large tactile touch cards for today's medications (touch target >= 48px).
3. Implement 3 primary one-touch action buttons:
   - Green: "I took this" -> transitions to `taken`
   - Amber: "Not yet" -> stays `not_yet` with gentle snooze
   - Red/Purple: "I'm not sure" -> transitions to `unsure` and alerts caregiver
4. Add single-touch Emergency / Caregiver call button.

## Acceptance Criteria
- Touch targets exceed 48px.
- Status updates immediately reflect in UI.
- Simplified language without confusing medical jargon.
