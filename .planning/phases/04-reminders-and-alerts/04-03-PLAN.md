# Plan 04-03: Caregiver Alert Feed & Real-Time Notification UI

## Objective
Display prominent alerts and badges on the caregiver interface for overdue and unsure doses, requiring proactive action.

## Tasks
1. Build Alert Banner component with visual urgency indicators.
2. Build Alert Feed showing all open unresolved alerts for linked elders.
3. Add quick action button to directly phone the elder or initiate claim.

## Acceptance Criteria
- Caregiver dashboard shows prominent alert banner when open alerts exist.
- Alert contains medication name, elder name, scheduled time, and current dose state.
