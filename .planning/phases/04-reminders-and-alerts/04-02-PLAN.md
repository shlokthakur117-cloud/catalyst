# Plan 04-02: Overdue Dose Detection & Caregiver Escalation Runner

## Objective
Implement background check logic that evaluates scheduled doses against current time, marks overdue doses as `unconfirmed`, and opens high-priority caregiver alerts.

## Tasks
1. Build escalation runner (`src/services/escalation-runner.ts`):
   - Query doses with status `not_yet` whose scheduled window (e.g. +60 minutes) has passed.
   - Transition status deterministically to `unconfirmed`.
   - Create a `caregiver_alerts` record with `alert_type: 'unconfirmed_dose'`.
   - Send immediate alert notification to linked caregivers.
2. Implement immediate escalation trigger for any dose marked `unsure`.
3. Add unit tests for escalation runner.

## Acceptance Criteria
- Overdue dose triggers transition to `unconfirmed` and opens alert.
- Doses marked `unsure` trigger immediate caregiver alert record.
