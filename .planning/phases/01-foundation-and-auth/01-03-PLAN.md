# Plan 01-03: Supabase Client, Auth & Elder-Caregiver Linking Layer

## Objective
Implement resilient Supabase client/server authentication helpers, session context, user profile management, and elder-caregiver linking logic.

## Tasks
1. Install `@supabase/supabase-js` and `@supabase/ssr`.
2. Configure browser client (`src/lib/supabase/client.ts`) and server client (`src/lib/supabase/server.ts`).
3. Implement in-memory/mock fallback store for offline tests and deterministic local CI (`src/lib/mock-store.ts`).
4. Implement Auth and Role Provider context (`src/contexts/auth-context.tsx`).
5. Implement Elder-Caregiver invitation/linking service (`src/services/relationship-service.ts`).
6. Write unit tests for relationship service and mock store.

## Acceptance Criteria
- Auth context handles Elder vs Caregiver roles seamlessly.
- Caregiver can generate and claim relationship link with Elder.
- Unit tests verify relationship linking logic and permission checks.
