# Plan 01-01: Initialize Next.js 15, Tailwind, TypeScript & Testing Framework

## Objective
Scaffold the core Next.js 15 App Router project in the root workspace with TypeScript, Tailwind CSS, Lucide React icons, and Vitest test suite.

## Tasks
1. Initialize package.json with Next.js 15, React 19, TypeScript, Tailwind CSS, Lucide React, and Vitest.
2. Configure `tsconfig.json`, `tailwind.config.ts`, `postcss.config.mjs`, and `vitest.config.ts`.
3. Set up project folder structure: `src/app`, `src/components`, `src/lib`, `src/types`, `src/services`, `tests`.
4. Create baseline test to verify Vitest configuration.
5. Verify build (`npm run build`) and test execution (`npm test`).

## Acceptance Criteria
- `npm run build` succeeds without errors.
- `npm test` runs and passes.
- Project follows clean modular structure.
